# 20 - Changelog & Release Notes

## Version 1.0.0 (Initial Commercial Release)

### Core Features Included:
- **Spring Boot 3.4.3 Backend**: Clean modular architecture with REST API controllers, services, repositories, and exception handling.
- **React 19 + Vite 8 Frontend**: High-performance UI with responsive design tokens, mobile navigation, skeleton loaders, and interactive toast alerts.
- **Capacitor 8 Android Mobile Application**: Hardware camera, GPS location, and deep-link UPI intent launching.
- **MongoDB Atlas Integration**: 2dsphere geospatial spatial indexing, compound availability indexes, and automatic schema initialization.
- **Stateless JWT Security**: BCrypt password hashing, role-based route access controls (`ROLE_USER`, `ROLE_OWNER`, `ROLE_ADMIN`).
- **Dynamic UPI Payment System**: Real-time UPI QR code generation (ZXing), 15-minute reservation locks, and anti-duplicate UTR validation.
- **Vehicle Inspection Pipeline**: Pre-trip check-in and post-trip return condition verification with photo uploads.
- **Cloudinary Storage**: Automated client-side image compression, CDN storage, and asset cleanup.
- **Multi-Provider Email System**: Failover across Brevo HTTP API, Resend HTTP API, JavaMailSender SMTP, and dev console logging.
- **Comprehensive Documentation**: 20 technical guides and setup walkthroughs.
