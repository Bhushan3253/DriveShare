# 15 - Host / Vehicle Owner Guide

## Host Walkthrough

### 1. Register as a Host
- Click **Sign Up** -> choose **List My Car / Host**.
- Log in and navigate to the **Host Portal** (`/owner/dashboard`).

### 2. Listing a New Vehicle (`/owner/cars/add`)
1. **Basic Info**: Brand, Model, Year, Body Type, Seating Capacity, Transmission, Fuel Type.
2. **Pricing & Location**: Daily rental rate in ₹/day, pick exact parking pin on interactive map.
3. **Photos**: Upload front, side, and interior pictures.
4. **Compliance Documents**: Upload RC Book, Insurance Policy, and Pollution (PUC) certificate.
5. Click **Submit Listing for Moderation**.

### 3. Managing Availability Windows (`/owner/cars/{id}/edit`)
- Define active rental date windows (e.g. Next 90 days).
- Block specific dates for vehicle maintenance or personal usage.

### 4. Tracking Bookings & Confirmations (`/owner/bookings`)
- View incoming bookings, payment verification status, renter identity, and trip dates.
- Review renter pre-trip and post-trip condition inspection photos.
- Mark trip as **Completed**.

### 5. Host Earnings & Payouts (`/owner/earnings`)
- Real-time earnings ledger showing:
  - Gross Bookings Volume
  - Platform Fee (15%)
  - Net Host Earnings (85%)
  - Settled vs Pending Payout balances.
